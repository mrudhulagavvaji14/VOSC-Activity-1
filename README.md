# Tic-Tac-Toe Game

## Description

This is a simple two-player Tic-Tac-Toe game developed using HTML, CSS and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the `index.html` file in a web browser.
2. The Tic-Tac-Toe game will start.

## How to Play

1. Player X starts the game.
2. Players take turns selecting empty boxes.
3. The first player to get three symbols in a row wins.
4. If all the boxes are filled without a winner, the game is a draw.
5. Click the Restart Game button to start a new game.

## Features

- Two-player gameplay
- Winner detection
- Draw detection
- Restart button
- Simple design
